# Jig

A plugin is a URL. Dereference it and it runs in a browser, with nothing to install. Jig is the plugin format native
to the web.

- **[Demo](https://strandz.it/jigdaw/simple.html)**: pick a tune, press Play, change the sound.
- **[Example plugins](catalogue.html)**: the worked plugins, with their panels.
- **[Guide for plugin developers](for-plugin-authors.md)**: make a plugin loadable anywhere.
- **[Guide for DAW developers](for-hosts.md)**: load other people's plugins.
- **[Specification](host-plugin-contract.md)**: what a host and a plugin must do.

More: the [overview](overview.md), the [maintainer's version](overview-danny.md) and the
[revisions](revisions.md) log.
