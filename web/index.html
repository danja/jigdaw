Local agent (experimental)

Runs a tool-calling loop against a local model's chat API, in this page. Nothing new listens for a connection: the loop reads jigdaw.mcp.tools and calls jigdaw.mcp.call itself, the same surface the console already has. Tested against Ollama on 127.0.0.1:11434. A page loaded over https:, such as the strandz.it deployment, cannot reach an http: endpoint at all, mixed content; this only works loaded over http:, such as the local dev server npm run serve starts.
